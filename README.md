## ✨ Features

- **Sticky Navigation Header** — smooth scroll highlighting active section
- **Animated Hero Section** — avatar ring, background glow, and status badge
- **Stats Row** — 3 Internships · 3+ Projects · 2 Research Papers · AI Specialization
- **Skills Grid + Animated Skill Bars** — Python, Deep Learning, Data Science, Java/C
- **Tabbed Experience Section** — Internships / Education / Positions of Responsibility
- **Filterable Projects Grid** — filter by All / AI·ML / Research / Systems
- **Credentials & Achievements** — Research papers, Silver Medal, and more
- **Contact Section** — with social links (LinkedIn, GitHub, Email)
- **Scroll-triggered animations** — elements fade/slide in on scroll using IntersectionObserver
- **Responsive Design** — works on desktop, tablet, and mobile

## 🚀 Getting Started

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/sumit961103/Portfolio_Website.git
   ```

2. **Open in browser**
   ```bash
   # Simply open the file directly
   start index.html        # Windows
   open index.html         # macOS
   xdg-open index.html     # Linux
   ```

No npm install, no build step — it just works.
